# Java Learning Notes

A structured collection of notes and code covering core Java fundamentals and OOP concepts.

---

## Structure

| Module | Topic |
|---|---|
| `00_IDE` | Setup, first program, data types, type casting |
| `01_Methods` | Methods, parameters, return types |
| `02_Operators` | Operators, conditionals, loops |
| `03_OOPs` | Classes, objects, inheritance, encapsulation, polymorphism |
| `04_How Java Works` | JDK, JVM, JRE, memory model, JIT compiler |
| `05_String and arrays` | Strings, StringBuffer, arrays |
| `06_Packages and Access specifiers` | Packages, access modifiers, `final` keyword |
| `07_abstract and Interfaces` | Abstract classes, interfaces |
| `08_exceptionHandling` | try/catch, checked vs unchecked, custom exceptions |
| `09_collections` | ArrayList, HashSet, HashMap, Iterator, Collections |
| `10_threads` | Multithreading, synchronization, ExecutorService |
